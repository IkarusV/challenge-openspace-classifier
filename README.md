# Room shuffler

## **Description**

This is a program designed to promote teamwork in the workspace, specially in open space.

It's function are to take a list of name from a *new_colleagues.cvs* 

Then to shuffle those names in randoms tables, so they can be distributed each time differantly and make people get used to working wiht everoyne, who in return will make everyone more efficient.

**Another plus** is that if everybody know, everyone strong suit and weak suit it'll be easier to relegate work to the right person so it's important to invest in such thing early in your work environement before thing settle too hard !

### **Installation**


To install it you need:
- python 3.14
- window,mac,linux os
- a terminal

git clone the current repo or dowload it manually into a folder, the folder structure must always have utils be in a folder right under main, the input and output must be and will be created always be created in the same location as main.py


### **Usage**

1. Input your name list in this format **"
Name1 
Name2 
Name3
Name4"**
make sure to have each name separate by a new line(/n).
2. Open terminal or IDE, or any of your prefered methode to run this scripts exemple(python.exe .\main.py) #window path in my case.
3.You should see in logs/terminal a display showing you the list or truncated list of name, it mean it worked and an ouput files should have been creater/or reshufled.
